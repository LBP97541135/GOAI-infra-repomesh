## 联调中发现并修复的问题

1. Matrix 普通文本不能稳定唤醒指定 Worker：改为解析 Worker Matrix 身份，写入完整 mention 和 `m.mentions`。
2. AgentTeams 原生 MCP Bearer Token 被 API 拒绝：Worker MCP 同时支持原生 Bearer 和既有自定义头。
3. API 镜像未包含能力文件：Docker 镜像加入 `capabilities/`。
4. API 容器 worktree 的 `.git` 指向容器绝对路径，宿主 Runner 无法采集 diff 和提交：改为相对 gitdir，宿主机与容器均可使用。
5. 一次重建时挂载源配置错误：上下文校验按预期拒绝任务并报告 `context_manifest_missing`；恢复正确宿主目录挂载后重测通过。
