6十二条裁决(评审通过即冻结)

#裁决
D-1Leader 决策面走 HTTP agent-actions,不建 MCP server——六成员皆 external,一个 adapter 的 seam 是假 seam
D-2拆解模式 per-team server|leader,默认 server;Materialize adoption external leader 时正式持久化 leader mode,并在前端只读展示
D-3复用现有出站 Matrix event_id,room_stream 按 event_id 去重;不重复改发送契约
D-4身份映射不到的消息如实存 raw matrix_user_id——如实的未知不是错误身份
D-5enrollment/binding 升 v2 新文件增 role;server provision/preflight 与 Bridge 同步理解 v2;v1 原文不动
D-6REPOMESH_RUNNER_WORKER_TOKENS 语义推广为 external 成员 token map,变量名不改(历史名+文档注记)
D-7Q5 收窄:带任务包的 WORKER 任务,房间 agent-report 一律 IGNORED(落审计)——coding 真相只走 Runner events
D-8Leader 协调会话只给纯文本工作包,不给 repo workspace——AC-02 纵深防御,最小知情面
D-9owning application 组装 DeliveryTraceability(issue/changeSet/plan/repo/task/run/worker/commit),SCM adapter 不跨模块反查
D-10共享 Codex 登录 = 开通脚本复制 auth.json 进六个 codex-home,不改产品代码
D-11ExternalWorker 泛化为 ExternalMember:只允许 Worker/Repository Leader,拒绝 Organization Leader;房间按角色生成
D-12GitHub delivery 仅在隔离 V2 环境对白名单三仓短时开启;V1 不开,V2 后关闭
